# 时间、日期与星期

默认 `flash_rw=0` 模式上电后自动发起一次 `ApiRefresh_StartTime()`，通过 ESP 取 NTP 时间。成功后用 UTC Unix 秒数加返回的 `utc_offset` 建立本地时间，并与 ACK 的日期、时刻和星期交叉检查。不额外给已包含时区的日期字符串再加偏移。

后续完全使用 TIM10 系统共享心跳走时，不周期联网、不随天气请求校时。启动请求失败、超时或时间字段不一致时显示 `--:--`、`周--`、`----/--/--`，打印失败日志，不自动重试。重新启动设备才重新执行启动校时。`api_time` 和 `esp_read time` 仍可用于手动协议诊断，但不会重新设置已经结束启动校时流程的本地时钟。

## 共享心跳

TIM10 保留现有 PSC=83、ARR=999 配置及中断优先级。在当前 84 MHz APB2 定时器时钟配置下，理论周期是 `84×1000/84000000 = 1 ms`，未改系统时钟树或其他定时器。

```text
TIM1_UP_TIM10_IRQHandler
  -> HAL_TIM_IRQHandler
  -> HAL_TIM_PeriodElapsedCallback
  -> SystemHeartbeat_Tick1ms（仅累加一次共享计数）
```

`SystemHeartbeat_Init()` 只在 TIM10 启动前执行一次。API 请求超时、本地走时和其他主循环任务通过 `SystemHeartbeat_Millis()` 读取同一个计数源，各自保留上次处理时刻；任务不能重置共享计数。`ApiRefresh_Init()` 不再重置时间源。旧 `ApiRefresh_Tick1ms()` 只是兼容转发入口，不能与 `SystemHeartbeat_Tick1ms()` 在同一次中断中重复调用。

`LocalClock_Poll()` 在 `EPD_UI_Poll()` 内、API 状态机处理后执行。中断不联网、不绘图、不做日历运算。主循环一次延迟数秒时会补算累计毫秒并保留不足一秒的余数，支持秒/分/时进位、月份长度、闰年、跨年和星期循环。无符号差值处理约 49.7 天一次的毫秒计数回绕；要求两次主循环处理间隔小于一个完整回绕周期。

## 显示与局刷

时间仍位于 `(250,6)`，使用 24px 字体显示 `HH:MM`；星期仍位于 `(322,2)`，16px 字体。完整 `YYYY-MM-DD` 日期宽 80px，调整到 `(320,18)` 右对齐 400px 屏幕边缘。显示前清除右上角旧字，避免数字替换残留。

- 首次校时成功、休眠/复位/底图失效后先整屏刷新建立基准。
- 仅时间变化时，分钟改变才调用 `refreshClock()`，局刷 `(248,0,152,40)`；跨日时同一次局刷包含日期和星期，不刷新天气、一言和待办。
- 天气或一言更新沿用整屏刷新，顺便带上最新时间。普通局刷连续 30 次后，下一次更新用全刷维护画面，计数归零；参数为 `CLOCK_PARTIAL_LIMIT`，实际残影情况仍需上板确认。
- 时钟运行时，业务刷新后保留控制器状态，不调用深度休眠，否则会丢失下一次局刷需要的底图。未校时或显示失败时仍尝试深睡。
- API 忙碌期间推迟时钟显示，心跳继续走时；空闲后只补刷最新分钟。自动显示间隔至少 5 秒，不因补算多个分钟而连续刷屏。
- 显示故障不立即循环重试；下一分钟会按失效基准全刷恢复，也可手动 `ref_epd`。`ref_epd` 是显式全刷，不再由 Shell 额外强制休眠。

`epd_partial_test` 保留独立测试流程及结束休眠行为。若时钟已启动，下一分钟更新会恢复业务画面。

## 验证与范围

自动更新时间后整屏变灰的硬件日志已确认：首次局刷 5172 ms，全刷 5620 ms，均无 HAL 错误。已按 HINK-E042A13-A0 社区参考程序修订底层局刷波形，详见 [局刷说明](PARTIAL_REFRESH.md)。效果尚待实测；原有黑底单次白块测试成功不等同于混合底图和连续更新已通过。

串口会输出 `UI: full begin` 或 `UI: clock partial begin x=248 y=0 w=152 h=40`，结束日志包含 `status`、`elapsed_ms` 和 `partial_count`。复现时保留从上电首次全刷到变灰后的这些日志，用来区分实际调用路径、首次/后续局刷及异常短的返回时间。`status=0` 只说明 HAL 未报告通信错误，不能证明刷新效果正确。诊断日志不改变刷新频率、窗口或底层命令，也未新增旧图缓存。

本机测试见 [MainUI 测试](../tests/main_ui/README.md)，覆盖启动仅请求一次、失败不重试、共享心跳不被通信初始化重置、UTC 正负偏移、校时字段一致性、闰年/世纪年/跨年、星期变化、延迟补算、计数回绕、无效时间占位符、分钟局刷窗口、API 忙时推迟、维护全刷和故障恢复。

固件构建和替身测试不代表实际 TIM10 周期、NTP 延迟、长期时钟漂移或连续局刷效果已经实测。一次校时后不补偿晶振误差，也不自动调整夏令时；时区沿用上电 ACK。当前未烧录本次固件，仍需真实设备验证。
